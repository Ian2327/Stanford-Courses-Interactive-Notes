    Conventions that cost points when mixed up

    • Row vs column. Distributions are row vectors and act from the left: \(\mu_{t+1} = \mu_t P_\pi\). Functions (\(r, V\)) are column vectors: \(P_\pi V\). The scalar \(\mu r = \sum_s \mu(s) r(s)\).
    • Rows sum to one, columns don’t. \(\sum_{s'} P_{ass'} = 1\), so \(P\mathbf 1 = \mathbf 1\). There is no such fact about column sums.
    • Induced quantities. \(P_{\pi ss'} = \sum_a \pi(a|s)P_{ass'}\) and \(r_\pi(s) = \sum_a \pi(a|s) r(s,a)\). For a deterministic policy, row \(s\) of \(P_\pi\) is row \(s\) of \(P_{\pi(s)}\).
    • Random payoffs. If the real payoff depends on the outcome, set \(r(s,a) = \mathbb E[\text{payoff}\mid s,a]\); expected returns don’t change (linearity and the tower property).

    The key identity: \(\mathbb E_{s,\pi}[R_{t+1}] = (P_\pi^t r_\pi)(s)\). Every expected return is built from it.

    L1

    Specification

    An MDP is a hypothesis about how state evolves under actions. The state must carry everything needed to predict the next state and compute the reward.

    Two equivalent tuples

    \[ (\mathcal S, \mathcal A, P):\; P_{ass'} = \mathbb P(S_{t+1}=s' \mid S_t=s, A_t=a) \qquad (\mathcal S,\mathcal A,\mathcal W, f,\nu):\; S_{t+1} = f(S_t, A_t, W_{t+1}),\; W_{t+1}\sim \nu(\cdot|S_t,A_t) \]
    \[ P_{ass'} = \nu\big(\{w : f(s,a,w) = s'\}\mid s,a\big); \quad\text{conversely, } W\sim\mathrm{Unif}[0,1] \text{ and } f = \text{inverse CDF of row } P_{as\cdot}. \]

    Policies

    • General: \(\pi(a|h)\) maps a history \(H_t = (S_0,A_0,\dots,S_t)\) to action probabilities.
    • Stationary: depends on \(H_t\) only through \(S_t\). Deterministic stationary: one action per state, written \(\pi(s)\).
    • Examples: “fast if \(s>10\)” is deterministic stationary; “fast w.p. \(1-e^{-s/10}\)” is stochastic stationary; “fast for the first 10 steps” and “don’t return to the previous vertex” are not stationary. The \((\bar s, \underline s)\) inventory policy orders \(\bar s - s\) when \(s \le \underline s\).
    Trap: the 2-dimensional pursuit model (relative position, velocity) is only enough if the reward depends on distance alone. Choose the state for the reward you need, not just the dynamics.
    L2

    Dynamics

    A stationary policy turns an MDP into a Markov chain \((\mathcal S, P_\pi)\). Limits of \(\mu_t\) can fail; time averages never do on a finite chain.

    \[ \mathbb P(S_{t+1}=s' \mid S_0,\dots,S_t) = \sum_a \pi(a|S_t) P_{aS_ts'} = P_{\pi S_t s'} \qquad \mu_{t+1} = \mu_t P_\pi,\quad \mu_t = \mu_0 P_\pi^t \]
    • Markov needs stationarity. Routing that avoids the previous vertex is not Markov in \(S_t\). Under a stationary policy, \((S_t, A_t)\) is also Markov.
    • Continuous state: use the kernel \(P_a(B|s) = \nu(\{w : f(s,a,w)\in B\}|s,a)\).
    • Monte Carlo: an event decided by \(H_T\) has probability ≈ the fraction of simulated runs in it; expectations are sample averages.

    Steady state

    Objectives

    Rewards score a step, returns combine steps along a trajectory, and expectations score a policy. In state-action frequencies the gain is linear, so optimizing it is a linear program.

    ReturnFormulaWhen to use
    Total\(\sum_{t\lt T} R_{t+1}\)fixed horizon (revenue management); infinite sums are usually \(\pm\infty\)
    Discounted\(\sum_t \gamma^t R_{t+1}\)random lifespan \(\sim\mathrm{Geom}\) with mean \(\tfrac1{1-\gamma}\), or time preference (consumption)
    Average (gain)\(\lim \tfrac1T\sum_{t\lt T}R_{t+1} = \lim_{\gamma\uparrow1}(1-\gamma)\sum_t\gamma^tR_{t+1}\)tiny steps, long horizon (internet switch); ignores any finite stretch
    Relative (bias)\(\lim_{\gamma\uparrow1}\sum_t\gamma^t(R_{t+1}-\lambda)\)breaks ties in gain; Tetris that may end has \(\lambda=0\) and bias = total
    \[ \sum_{T\ge1}(1-\gamma)\gamma^{T-1}\sum_{t\lt T}R_{t+1} = \sum_{t\ge0}\gamma^tR_{t+1} \quad\text{(discounting = averaging over a geometric lifespan)} \]

    Matrix forms (finite MDP, stationary π)

    \[ \text{total } \sum_{t\lt T}P_\pi^t r_\pi,\quad \text{disc. } (I-\gamma P_\pi)^{-1}r_\pi,\quad \text{gain } \lambda_\pi = \mu_\pi r_\pi,\quad \text{bias } \lim_{\gamma\uparrow1}\sum_t\gamma^t(P_\pi^tr_\pi - \lambda_\pi\mathbf 1) \]

    State-action probabilities

    \[ \lambda_\pi = \sum_{s,a}\mu_\pi(s,a)r(s,a),\quad \sum_{a'}\mu(s',a') = \sum_{s,a}\mu(s,a)P_{ass'},\quad \sum_{s,a}\mu(s,a) = 1,\quad \mu\ge0 \]
    • Polytope: the feasible \(\mu\) form a polytope; vertices are exactly the deterministic stationary policies, so the LP optimum gives a deterministic optimal policy.
    • Recover the policy: \(\pi(a|s) = \mu(s,a)/\sum_{a'}\mu(s,a')\). No \(P\) needed.
    • Discounted version: \(\mu_\pi(s,a) = (1-\gamma)\mathbb E_{S_0,\pi}\sum_t\gamma^t\mathbf 1_{s,a}(S_t,A_t)\), with balance \(\sum_{a'}\mu(s',a') = \gamma\sum_{s,a}\mu(s,a)P_{ass'} + (1-\gamma)\mathbf 1_{S_0}(s')\): continue w.p. \(\gamma\), else restart at \(S_0\).
    • Pathologies (countable \(\mathcal A\), \(r = 1-1/a\)): no optimal policy at all, or an optimal policy (\(A_t = t+1\)) but no stationary optimal one. They almost never arise in practice.
    Trap: \(P_\pi r_\pi\) is the vector of next-step expected rewards, not the gain. The gain is the scalar \(\mu_\pi r_\pi\), and it is state-independent only with a single recurrent class.
    L4

    Value functions and Bellman equations

    Value functions predict returns, not immediate reward. Acting greedily on \(Q_\pi\) improves \(\pi\), and acting greedily on \(Q_*\) turns a multi-step problem into a one-step one.

    \[ Q_{\pi,\gamma}(s,a) = r(s,a) + \gamma\sum_{s'}P_{ass'}V_{\pi,\gamma}(s'),\quad Q_\pi(s,a) = r(s,a) - \lambda_\pi(s) + \sum_{s'}P_{ass'}V_\pi(s'),\quad \eta_\pi(s,a) = \sum_{s'}P_{ass'}\lambda_\pi(s') \]
    \[ V_{\pi,\gamma}(s) = \frac{\lambda_\pi(s)}{1-\gamma} + V_\pi(s) + O(1-\gamma) \quad\text{(Laurent expansion)} \]
    ObjectivePolicy Bellman equationOptimal Bellman equation
    Discounted\(V = r_\pi + \gamma P_\pi V\), unique\(V(s) = \max_a(r + \gamma\sum P V)\), unique
    Total\(V_{\pi,\tau+1} = r_\pi + P_\pi V_{\pi,\tau}\), \(V_{\pi,0}=0\)\(V_{*,\tau+1} = \max_a(r + PV_{*,\tau})\); optimal policy depends on time-to-go
    Gain/bias\(\lambda = P_\pi\lambda\), \(V = r_\pi - \lambda + P_\pi V\); solutions \((\lambda_\pi, V_\pi + g)\) with \(P_\pi g = g\)\(\lambda(s) = \max_a\sum P\lambda\); \(V(s) = \max_{a\in\mathcal A_*(s)}(r - \lambda + \sum PV)\); any solution has \(\lambda=\lambda_*\)
    • Greedy: \(\mathrm{supp}\,\pi'(\cdot|s)\subseteq\arg\max_aQ(s,a)\). For gain/bias, be greedy on \(\eta_\pi\), then break ties with \(Q_\pi\).
    • Policy improvement: \(V_{\pi',\gamma}\ge V_{\pi,\gamma}\), strictly at some state unless \(\pi\) is optimal. For gain/bias: \(\lambda_{\pi'}\ge\lambda_\pi\), and if equal then \(V_{\pi'}\ge V_\pi\).
    • Rollouts: \(Q_{\pi,\gamma}(s,a)\approx\frac1K\sum_k\sum_t\gamma^tr(S^k_t,A^k_t)\); cost scales with \(K|\mathcal A|\); \(K=1\) suffices with deterministic dynamics. Iterated rollouts cost grows exponentially in the number of levels.
    • Solitaire: five rollout iterations on thoughtful solitaire reach about 70% wins, roughly double a mathematician’s 36.6%.
    • Shadow prices: the dual variables of the balance constraints in the gain LP are the optimal bias \(V_*\).
    Examples: the capped queue (arrivals 0.5, service 0.7 fast / 0.4 slow, fast costs 30, abandonment 500, \(\gamma=0.99\)) is optimal with slow service up to 12 waiting customers. In the 5-cell mopbot with no spills, the optimal policy heads to the center cell.
    Trap: greedy always means greedy on \(Q\) (reward plus future), never on \(r\) alone. And the bias Bellman equation alone doesn’t pin \(V_\pi\) down; add \(\mu_\pi V_\pi = 0\).
    L5

    Value iteration

    Apply \(T\) repeatedly. With a finite horizon this is exact backward induction; with discounting it converges geometrically because \(T\) is a \(\gamma\)-contraction.

    \[ (T_\pi V)(s) = \sum_a\pi(a|s)\Big(r(s,a) + \gamma\sum_{s'}P_{ass'}V(s')\Big),\qquad (TV)(s) = \max_a\Big(r(s,a) + \gamma\sum_{s'}P_{ass'}V(s')\Big) \]
    \[ \|TV - TV'\|_\infty\le\gamma\|V-V'\|_\infty \;\Rightarrow\; \|V_* - \tilde V_k\|_\infty\le\gamma^k\|V_* - \tilde V_0\|_\infty \]
    • Contraction proof: \(\max_af_a - \max_ag_a\le\max_a(f_a - g_a) = \gamma\max_a\sum_{s'}P_{ass'}(V-V')(s')\le\gamma\|V-V'\|_\infty\), then swap roles.
    • Total VI: \(\tilde V_0 = 0\), \(\tilde V_{k+1} = T\tilde V_k\) gives \(\tilde V_T = V_{*,T}\) exactly. Shortest path is Bellman–Ford (reward \(-d(s,a)\) plus a large bonus at the destination; value 60 = 70 − (3+2+5) in the lecture graph).
    • Asynchronous: update any subsets, each state infinitely often, and it still converges; tolerant to communication delays. Gauss–Seidel (in place) often beats Gauss–Jacobi (all at once). River swim: one Gauss–Seidel sweep versus \(|\mathcal S|\) Jacobi iterations.
    • Gain/bias VI: \(J_{k+1} = TJ_k\) with \(\gamma = 1\); \(\tilde\lambda_{k+1} = J_{k+1}-J_k\to\lambda_*\), \(\tilde V_k = J_k - k\tilde\lambda_k\); valid when gain-optimal policies are aperiodic.

    Linear-quadratic control (scalar)

    \[ x' = ax + bu + w,\; r = -x^2 - cu^2:\quad V_k(x) = \text{const} + \eta_kx^2,\quad u^* = -\frac{\eta_kab}{\eta_kb^2 - c}x,\quad \eta_{k+1} = -1 + a^2\Big(\eta_k - \frac{\eta_k^2b^2}{\eta_kb^2 - c}\Big) \]

    Discounted: replace \(a^2\) with \(\gamma a^2\) and \(c\) with \(c/\gamma\). The fixed-point equation is quadratic with two roots; the negative one is \(\eta_*\).

    Trap: stopping rule \(\|\tilde V_k - V_*\|_\infty\le\frac{\gamma}{1-\gamma}\|\tilde V_k - \tilde V_{k-1}\|_\infty\). A small change between iterates doesn’t mean a small error when \(\gamma\) is near 1.
    L6

    Policy iteration

    Evaluate exactly, then act greedily. Monotonicity turns one improvement step into a chain of inequalities, and finitely many deterministic policies forces termination.

    \[ V_{\pi,\gamma} = (I-\gamma P_\pi)^{-1}r_\pi \qquad V_\pi = T_\pi V_\pi\le TV_\pi = T_{\pi'}V_\pi \;\Rightarrow\; V_\pi\le T_{\pi'}V_\pi\le T_{\pi'}^2V_\pi\le\cdots\le V_{\pi'} \]
    • Monotonicity: \(V\le V'\Rightarrow TV\le TV'\) and \(T_\pi V\le T_\pi V'\), because \(\gamma\ge0\) and \(P\ge0\).
    • Termination: if \(V_{\pi'} = V_\pi\) then \(V_\pi = TV_\pi\), so \(V_\pi = V_*\). Finite convergence follows.
    • Queue: starting from always-slow, the thresholds converge to 13 in six iterations. Each iteration costs far more than a value-iteration sweep.
    • Approximate PI: fit \(\tilde V_\theta(s) = \theta_0 + \theta_1s + \theta_2s^2\) by least squares; the threshold settles at 9 instead of 13, with nearly the same performance. Rollout targets from sampled start states remove the dependence on \(|\mathcal S|\).

    L7

    Linear programming

    \(V_*\) is the smallest \(V\) with \(V\ge TV\). One constraint per state-action pair makes that a linear program; its dual is the state-action-frequency LP from L3.

    \[ \min_V\sum_sw(s)V(s)\quad\text{s.t. } V(s)\ge r(s,a) + \gamma\sum_{s'}P_{ass'}V(s')\;\;\forall s,a \qquad\Longleftrightarrow\qquad \min\ w^\top V \text{ s.t. } V\ge TV \]
    • Proof: feasible means \(V\ge TV\ge T^2V\ge\cdots\to V_*\), and \(V_*\) is feasible. So \(V_*\) is the unique optimum for any weights \(w > 0\).
    • Reading the solution: binding constraints mark greedy (optimal) actions. Toy example (\(\epsilon=0.1\), \(\gamma=0.9\)): (1, stay) and (2, move) bind.
    • Gain LP: \(\min_{\lambda,V}\lambda\) s.t. \(V\ge TV - \lambda\), derived by substituting the Laurent expansion and letting \(\gamma\uparrow1\); optimal solutions are \((\lambda_*, V_* + \eta\mathbf 1)\).
    • Approximate LP for Tetris: \(\tilde V_\theta = \sum_{k=1}^{22}\theta_k\phi_k\) (column heights, height differences, max height, holes, constant), sampled states for the objective, constraints kept only at sampled states, then re-simulate and re-solve (bootstrapping).

    The primals

    \[ \text{average: } \max_\mu\sum\mu r \text{ s.t. } \sum_{a'}\mu(s',a') = \sum_{s,a}\mu(s,a)P_{ass'},\ \sum\mu = 1,\ \mu\ge0 \qquad \text{discounted: } \sum_{a'}\mu(s',a') = 1 + \gamma\sum_{s,a}\mu(s,a)P_{ass'} \]
    Trap: the problem \(\max\sum V\) s.t. \(V\le TV\) also has \(V_*\) as its unique solution, but it is not an LP: \(V\le TV\) means “some action satisfies it,” a union of polyhedra, which can be nonconvex (HW6).

    Real-time value iteration and Q-learning

    Update only where a simulated trajectory goes. Optimism keeps good actions in play; Q-learning replaces the expectation with one sampled next state and smooths with a step size.

    \[ (FQ)(s,a) = r(s,a) + \gamma\sum_{s'}P_{ass'}\max_{a'}Q(s',a'),\qquad FQ_* = Q_*,\qquad \|FQ - FQ'\|_\infty\le\gamma\|Q-Q'\|_\infty \]
    \[ Q_{t+1}(S_t,A_t) = Q_t(S_t,A_t) + \alpha_t\big(r(S_t,A_t) + \gamma\max_aQ_t(S_{t+1},a) - Q_t(S_t,A_t)\big) \]
    • RTVI: act greedily, apply \(F\) at the visited pair only. A pessimistic start can mean an optimal action is never tried (one state, \(Q_0 = -1\) on the good action).
    • Optimism is preserved: \(Q_0\ge Q_*\Rightarrow Q_t\ge Q_*\) by monotonicity. If \(Q_0\ge FQ_0\), the iterates decrease and eventually only optimal actions are taken. \(Q_t\) need not converge to \(Q_*\) at pairs that stop being visited.
    • Step sizes: \(\sum\alpha_t = \infty\), \(\sum\alpha_t^2\lt\infty\), each pair updated infinitely often (Jaakkola et al.; Tsitsiklis). Fixed steps chatter near the answer; smaller steps learn slower but settle closer.
    • Exploration: noise can make Q-learning pessimistic, so either add optimistic boosts \(\Delta_t\) or dither with ε-greedy.
    • Parameterized: \(\theta\leftarrow\theta + \alpha\nabla_\theta Q_\theta(S_t,A_t)\cdot\text{TD}\); tabular \(Q_\theta(s,a) = \theta_{s,a}\) recovers ordinary Q-learning.

    L9

    Policy gradient methods

    Reinforce nudges up the log-probability of actions in proportion to how well they turned out. In expectation that nudge is the policy gradient, and subtracting a baseline keeps it unbiased while cutting variance.

    \[ \theta_{t+1} = \theta_t + \alpha_t(R_{t+1} - B_t)\nabla_\theta\ln\pi_{\theta_t}(A_t),\qquad \nabla_\theta\lambda_\theta = \sum_a\pi_\theta(a)r(a)\nabla_\theta\ln\pi_\theta(a) = \mathbb E[R_{t+1}\nabla\ln\pi_\theta(A_t)] \]
    \[ \text{Gibbs: } \pi_\theta(a) = \frac{e^{\theta_a}}{\sum_{a'}e^{\theta_{a'}}},\quad \nabla_\theta\ln\pi_\theta(a) = \mathbf 1_a - \sum_{a'}\pi_\theta(a')\mathbf 1_{a'} \]
    • Baseline is free: \(\mathbb E[B_t\nabla\ln\pi(A_t)] = B_t\sum_a\nabla\pi(a) = B_t\nabla1 = 0\) for any \(B_t\) set by \(\theta_t\) and the history.
    • Why baselines matter: with rewards 0.96 vs 0.94, plain reinforce chatters and doesn’t settle; a running-average baseline converges reliably.
    • Policy gradient theorem: \(\nabla_\theta\lambda_\theta = \sum_{s,a}\mu_\theta(s,a)Q_{\pi_\theta}(s,a)\nabla_\theta\ln\pi_\theta(a|s)\); natural baseline \(V_{\pi_\theta}(S_t)\), giving the advantage \(Q - V\).
    • Estimating \(Q\): by rollouts, or by TD learning (actor-critic): \(d_{t+1} = R_{t+1} - \lambda_t + \tilde Q_\psi(S_{t+1},A_{t+1}) - \tilde Q_\psi(S_t,A_t)\), \(\psi\mathrel{+}=\beta d\nabla\tilde Q_\psi\), \(\lambda\mathrel{+}=\beta d\).
    • Episodic total return: \(\theta_{\ell+1} = \theta_\ell + \alpha_\ell\sum_{t\lt T}\hat Q_t\nabla\ln\pi_{\theta_\ell}(A_t|S_t)\) with \(\hat Q_t = \sum_{k\ge t}R_{k+1}\) from the same episode.
    • Language models: state = context window, action = next token, reward \(R_T\) = verified-correct answer; useful when answers are hard to produce but easy to check.

    Proof moves and decision guide

    These are the moves the homework and the 2025 midterm reused most.

    • Unpack to components. Show \((\mu P)_j = \sum_i\mu_iP_{ij} = \mu_j\) for an arbitrary \(j\), then conclude for all \(j\).
    • Monotone chain. \(V\le TV\Rightarrow V\le T^kV\to V_*\) (LP, policy improvement, modified PI).
    • Contraction. Write the error at step \(k+1\) as \(T\) applied to step \(k\) and pull out \(\gamma\).
    • Split and reindex. \(\sum_{t\ge0}\gamma^tX_t = X_0 + \gamma\sum_{t\ge0}\gamma^tX_{t+1}\), with \(P^{t+1} = PP^t\) (bias Bellman equation).
    • Steady state kills time. \(\mu_\pi P_\pi^t = \mu_\pi\) turns sums over \(t\) into geometric series (\(\mu_\pi V_\pi = 0\), \(\mu_\pi V_{\pi,\gamma} = \lambda_\pi/(1-\gamma)\)).
    • Justify every swap. Finite sums commute with limits and expectations; \(\mathbb E\) passes into \(\sum\gamma^t\) because rewards are bounded; keep \(\lim_{\gamma\uparrow1}\) outside.
    • Bound with balance plus nonnegativity. Write the objective in \(\mu\), bound the inflow, and read the optimal policy off the equality conditions (HW3 constrained MDP).
    • Small counterexamples. Two states, two actions (gain tie with different bias; nonconvex \(V\le TV\)).

    What the homework tests

    Problems mix four things: specify an MDP, compute a steady state, gain or bias by hand, prove a property with monotonicity or contraction, and confirm numerically in code. Each section below gives the setup, the results to know, and the move each proof uses.

    • Spec checklist: give \(\mathcal S\), \(\mathcal A\) (and \(\mathcal A(s)\)), each \(P_a\) as a matrix with rows summing to one, \(r(s,a)\) piecewise, and initial or terminal states.
    • Gain recipe: build \(P_\pi\), solve \(\mu P_\pi = \mu\) with \(\sum\mu = 1\), build \(r_\pi\), then \(\lambda = \mu r_\pi\).
    • Bias recipe: solve the \(n+1\) equations \(V + \lambda\mathbf 1 = r_\pi + P_\pi V\), \(\mu_\pi V = 0\).

    1.1

    The agent–environment loop

    At each time \(t\) the agent sees a state \(S_t\), picks an action \(A_t\), and the environment answers with a random next state \(S_{t+1}\). Everything in the course is about that loop.

    An MDP fixes three things: the set of states \(\mathcal S\) the environment can be in, the set of actions \(\mathcal A\) the agent can take, and the rule that generates the next state. The rule is random, and it may depend only on the current state and action. That restriction is what makes the problem tractable: the state is assumed to summarize everything about the past that matters for the future.

    There are two equivalent ways to write the rule. The first lists probabilities directly. The second describes an algorithm that draws some noise and computes the next state from it. Use whichever is easier to write down for the problem in front of you.

    FormTupleHow \(S_{t+1}\) is producedNatural when
    Probabilities\((\mathcal S,\mathcal A,P)\)sample from the row \((P_{A_tS_ts'})_{s'}\)small countable state spaces (queues, routing, Tetris)
    Transition function\((\mathcal S,\mathcal A,\mathcal W,f,\nu)\)draw \(W_{t+1}\sim\nu(\cdot|S_t,A_t)\), set \(S_{t+1}=f(S_t,A_t,W_{t+1})\)continuous states, or dynamics easiest to state as code (linear systems, inventory, LLMs)
    1.2

    Converting between the two forms

    From the function form to probabilities, add up the probability of all disturbances that send \(s\) to \(s'\):

    \[ P_{ass'} = \nu\big(\{w\in\mathcal W : f(s,a,w) = s'\}\mid s,a\big). \]

    The other direction always works for countable states: let the disturbance be uniform on \([0,1]\) and use it as an inverse-CDF lookup. Number the states \(1,\dots,N\), form the cumulative sums \(p_{ass'} = \sum_{s''\le s'}P_{ass''}\), and set \(f(s,a,w) = s'\) whenever \(w\in[p_{a,s,s'-1},p_{ass'})\). Each interval has length exactly \(P_{ass'}\), so the probabilities come out right.

    Worked example (inventory). With \(f(s,a,w)=\max(s+a-w,0)\) and Poisson demand, \(P_{ass'} = \Pb(W = s+a-s')\) for \(s'\gt0\), and \(P_{as0} = \Pb(W\ge s+a)\): every demand at least as large as the stock empties the shelf. The lost-sales max is why the zero state collects a whole tail of disturbances.
    1.3

    Choosing the state

    The state has two jobs. It must make the next-state distribution depend on nothing else, and it must carry whatever the reward needs.

    The pursuit example shows the second job. The vehicle’s position, velocity, and the target’s position make a 3-dimensional state \(x\in\mathbb R^3\) with

    \[ A = \begin{bmatrix}1&1&0\\0&1&0\\0&0&1\end{bmatrix},\quad B = \begin{bmatrix}0\\1/m\\0\end{bmatrix},\quad \Sigma = \begin{bmatrix}0&0&0\\0&0&0\\0&0&\sigma^2\end{bmatrix}. \]

    Replacing the two positions by their difference gives a 2-dimensional model that predicts the future just as well. Whether it is enough depends on the objective: if reward depends only on the distance, yes; if it depends on where the vehicle actually is, no. HW2 makes the same point from the other side: when utility depends on the last three consumption levels, you must add those two past levels to the state.

    Language models show how much freedom you have. The same chat can be modeled with one token per action (state = last \(M\) tokens, \(\mathcal A\) = vocabulary, no randomness at all) or one message per action (the response is the disturbance, generated token by token by a model \(\psi\)). Both are correct MDPs; they answer different questions.

    1.4

    Policies

    A policy maps the whole history \(H_t = (S_0,A_0,\dots,S_t)\) to a distribution over actions. Two restrictions matter all term.

    • Stationary: depends on \(H_t\) only through \(S_t\), so we write \(\pi(a|s)\). Under a stationary policy the states form a Markov chain (Lecture 2).
    • Deterministic stationary: one action per state, written \(\pi(s)\). For every infinite-horizon objective in the course there is an optimal policy of this kind (Lecture 3).

    Queue examples: “fast when \(s\gt10\)” is deterministic stationary; “fast with probability \(1-e^{-s/10}\)” is stationary but random; “fast for the first ten steps” depends on \(t\), so it is not stationary.

    2.1

    From policy to chain

    A stationary policy averages the action matrices into one transition matrix, and the Markov property follows from the tower property.

    \[ P_{\pi ss'} = \sum_a\pi(a|s)P_{ass'}, \qquad \Pb(S_{t+1}=s'\mid S_0,\dots,S_t) = \sum_a\pi(a|S_t)P_{aS_ts'} = \Pb(S_{t+1}=s'\mid S_t). \]

    The middle step is where stationarity is used: the probability of \(A_t=a\) given the whole past is \(\pi(a|S_t)\), which depends only on \(S_t\). With the no-backtracking routing policy that fails, because the action distribution depends on \(S_{t-1}\), and knowing \(S_{t-1}\) sharpens the prediction of \(S_{t+1}\).

    The same argument with Bayes’ rule shows that the pairs \((S_t,A_t)\) also form a Markov chain under a stationary policy. That is the chain whose long-run frequencies become the decision variables of the linear programs in Lectures 3 and 7.

    2.2

    The forward equation

    Write \(\mu_t(s) = \Pb(S_t=s)\) as a row vector. To be at \(s'\) at time \(t+1\), the chain was at some \(s\) at time \(t\) and moved:

    \[ \mu_{t+1}(s') = \sum_s\mu_t(s)P_{\pi ss'} \quad\Longleftrightarrow\quad \mu_{t+1} = \mu_tP_\pi \quad\Longrightarrow\quad \mu_t = \mu_0P_\pi^t. \]

    If \(S_0 = s\) is fixed, \(\mu_0 = e_s^\top\) and \(\mu_t\) is row \(s\) of \(P_\pi^t\). Applying \(P_\pi\) on the left of a column vector instead, as in \(P_\pi r_\pi\), computes an expectation one step ahead; the two uses are easy to swap by accident.

    Lecture figure. For the queue started empty, \(\mu_t\) spreads out and settles. With threshold 10 the steady distribution has a kink near 10, where service switches from slow to fast.
    2.3

    Steady state: existence and uniqueness

    If \(\mu_t\to\mu\), take limits on both sides of the forward equation to get the balance equation \(\mu = \mu P_\pi\). But the limit need not exist: the two-state swap \(P = \begin{bmatrix}0&1\\1&0\end{bmatrix}\) alternates forever. The time average always exists for a finite chain, and it solves balance:

    \[ \bar\mu = \lim_{T\to\infty}\frac1T\sum_{t=0}^{T-1}\mu_t, \qquad \bar\mu(s) = \lim_T\frac1{T-1}\sum_{t=1}^{T-1}\sum_r\mu_{t-1}(r)P_{\pi rs} = \sum_r\bar\mu(r)P_{\pi rs}. \]

    The proof drops the \(t=0\) term (which doesn’t affect a limit of averages), uses the forward equation, then pulls the finite sum over \(r\) outside the limit. So a steady state always exists. Uniqueness depends on recurrent classes: sets the chain never leaves once inside and in which it visits every state infinitely often. One recurrent class means one steady state. Two or more means infinitely many, since every convex combination of class-wise steady states works.

    Example. State 1 moves to absorbing states 2 or 3 with probability ½ each. Cesàro limits are \((0,\tfrac12,\tfrac12)\), \((0,1,0)\), \((0,0,1)\) from starts 1, 2, 3, and every \((0,\alpha,1-\alpha)\) is a steady state.

    Infinite chains can have none: a queue that always serves slowly while \(q\gt p_{\text{slow}}\) grows without bound. A positive recurrent state, one visited again in finite expected time, is enough to guarantee a steady state.

    3.1

    Rewards

    A reward function \(r:\mathcal S\times\mathcal A\to\mathbb R\) is a compact way to express preferences over entire trajectories. The trick is choosing one that induces the behavior you actually want.

    • Queue: \(r(s,a) = -s\). Each waiting customer costs one unit per step, so total reward is total waiting.
    • Consumption: \(r = a_2s\) (raw consumption) invites reckless bets; \(r = u(a_2s)\) with concave \(u\) gives sensible risk-taking (HW1).
    • Revenue management: reward is expected revenue over the next step, e.g. \(q_{\text{std}}p_{\text{std}} + q_{\text{vip}}p_{\text{vip}}\) when accepting. Random payoffs are replaced by their conditional means.
    • LLM math: reward 1 only at the end token when the solution verifies. Easy to check, hard to produce.
    3.2

    Four ways to combine rewards

    Each return fixes a problem with the one before it.

    • Total \(\sum_{t\lt T}R_{t+1}\) is natural with a horizon (tickets are worthless after the concert). Without one, many trajectories score \(+\infty\) and it can’t tell them apart.
    • Discounted \(\sum_t\gamma^tR_{t+1}\) is finite for bounded rewards. If the lifespan \(T\) is geometric with mean \(1/(1-\gamma)\), averaging total return over lifespans gives exactly the discounted return:
    \[ \sum_{T=1}^\infty(1-\gamma)\gamma^{T-1}\sum_{t=0}^{T-1}R_{t+1} = \sum_{t=0}^\infty R_{t+1}\sum_{T\gt t}(1-\gamma)\gamma^{T-1} = \sum_{t=0}^\infty\gamma^tR_{t+1}. \]
    • Average removes the choice of \(\gamma\): \(\lim_{\gamma\uparrow1}(1-\gamma)\sum_t\gamma^tR_{t+1} = \lim_T\frac1T\sum_{t\lt T}R_{t+1}\). It ignores anything that happens over a finite stretch.
    • Relative \(\lim_{\gamma\uparrow1}\sum_t\gamma^t(R_{t+1}-\lambda)\) recovers what the average throws away. In a Tetris game that ends, \(\lambda = 0\) and the relative return is the total.

    3.4

    State-action frequencies and the LP

    The gain is nonlinear in \(\pi\) but linear in \(\mu_\pi(s,a) = \mu_\pi(s)\pi(a|s)\), the long-run fraction of time spent at \(s\) taking \(a\):

    \[ \lambda_\pi = \sum_{s,a}\mu_\pi(s,a)r(s,a),\qquad \sum_{a'}\mu(s',a') = \sum_{s,a}\mu(s,a)P_{ass'},\quad \sum_{s,a}\mu(s,a) = 1,\quad \mu\ge0. \]

    The left side of the balance constraint is time spent at \(s'\); the right side is flow into \(s'\). Every \(\mu\) satisfying these comes from a policy, recovered by \(\pi(a|s) = \mu(s,a)/\sum_{a'}\mu(s,a')\). The feasible set is a polytope whose vertices are the deterministic policies, and a linear objective is maximized at a vertex. That is why an optimal deterministic stationary policy exists.

    For discounting, replace long-run frequencies with \(\mu_\pi(s,a) = (1-\gamma)\E\sum_t\gamma^t\mathbf 1_{s,a}(S_t,A_t)\). The balance equation gains a restart term, \(\sum_{a'}\mu(s',a') = \gamma\sum_{s,a}\mu(s,a)P_{ass'} + (1-\gamma)\mathbf 1_{S_0}(s')\), and \(\sum\mu r = (1-\gamma)V_{\pi,\gamma}(S_0)\).

    Pathologies. With countably many actions and \(r = 1 - 1/a\), every action is beaten by the next one, so no policy is optimal. Over an infinite horizon, \(A_t = t+1\) earns gain 1 but no stationary policy does. These need infinite action sets; they don’t arise in finite MDPs.

    4.1

    Three kinds of value

    Each objective from Lecture 3 has a value function: the expected return as a function of the starting state.

    \[ V_{\pi,T}(s) = \E_{s,\pi}\Big[\sum_{t\lt T}R_{t+1}\Big],\quad V_{\pi,\gamma}(s) = \E_{s,\pi}\Big[\sum_t\gamma^tR_{t+1}\Big],\quad V_\pi(s) = \lim_{\gamma\uparrow1}\E_{s,\pi}\Big[\sum_t\gamma^t(R_{t+1}-\lambda_\pi(S_t))\Big]. \]

    Optimal values maximize over policies. For bias the maximum is taken only over gain-optimal policies, since otherwise a policy could trade gain for bias. The Laurent expansion ties discounted value to gain and bias:

    \[ V_{\pi,\gamma}(s) = \frac{\lambda_\pi(s)}{1-\gamma} + V_\pi(s) + O(1-\gamma). \]

    Gain is the coefficient of the pole at \(\gamma = 1\); bias is the constant term. Maximizing gain then bias is like discounting with \(\gamma\) arbitrarily close to one.

    4.2

    Action values and greedy policies

    To compare actions, value the immediate reward plus what follows:

    \[ Q_{\pi,\gamma}(s,a) = r(s,a) + \gamma\sum_{s'}P_{ass'}V_{\pi,\gamma}(s'),\qquad Q_\pi(s,a) = r(s,a) - \lambda_\pi(s) + \sum_{s'}P_{ass'}V_\pi(s'),\qquad \eta_\pi(s,a) = \sum_{s'}P_{ass'}\lambda_\pi(s'). \]

    A policy is greedy with respect to \(Q\) if it only picks actions in \(\arg\max_aQ(s,a)\). The policy improvement theorem says greedy on \(Q_{\pi,\gamma}\) is at least as good as \(\pi\) from every state, and strictly better somewhere unless \(\pi\) is already optimal. Greedy on \(Q_{*,\gamma}\) is optimal, which turns a long-horizon problem into a one-step maximization. For gain and bias, be greedy on \(\eta_\pi\) first and break ties with \(Q_\pi\).

    4.3

    Rollouts

    Computing \(Q_\pi\) exactly costs time proportional to the state space. A rollout estimates it only where you are: from \(S_t\), for each action \(a\), simulate \(K\) trajectories that take \(a\) first and then follow \(\pi\), and average their returns. Acting on the argmax approximates the greedy policy \(\pi'\), so rollouts improve the base policy online.

    \[ Q_{\pi,\gamma}(s,a)\approx\frac1K\sum_{k=1}^K\sum_{t\ge0}\gamma^tr(S_t^k,A_t^k),\qquad\text{cost}\propto K|\mathcal A|\ \text{per decision}. \]

    With deterministic dynamics every rollout from the same pair is identical, so \(K=1\). Rolling out the rollout policy improves again, at exponentially growing cost. Thoughtful solitaire (all cards visible) went from a strong human’s 36.6% to about 70% after five iterations. HW4’s Tetris shows the same pattern: the height heuristic scores −4, its rollout 13, and the double rollout reaches the cap of 500.

    Trap: in a stochastic environment, one rollout per action is unbiased but noisy, and the argmax of noisy estimates can pick a worse action. Improvement is only guaranteed with exact \(Q_\pi\).
    4.4

    Bellman equations

    Value at a state is immediate reward plus value of where you land. For discounting both equations have unique solutions:

    \[ V_{\pi,\gamma}(s) = \sum_a\pi(a|s)\Big(r(s,a)+\gamma\sum_{s'}P_{ass'}V_{\pi,\gamma}(s')\Big),\qquad V_{*,\gamma}(s) = \max_a\Big(r(s,a)+\gamma\sum_{s'}P_{ass'}V_{*,\gamma}(s')\Big). \]

    For total value the equations run backward in time-to-go from \(V_{\cdot,0} = 0\), which is why optimal finite-horizon policies are usually nonstationary. For gain and bias, the policy equations \(\lambda = P_\pi\lambda\) and \(V = r_\pi - \lambda + P_\pi V\) determine \(V\) only up to adding \(g\) with \(P_\pi g = g\); with one recurrent class that means a constant, removed by \(\mu_\pi V = 0\). The optimal equations take a max over \(\mathcal A_*(s)\), the gain-maximizing actions, and any solution gives \(\lambda_*\) and a gain- and bias-optimal policy.

    5.1

    Bellman operators

    Packaging the right side of a Bellman equation as an operator turns equations into fixed-point statements and algorithms into repeated application.

    \[ (T_\pi V)(s) = \sum_a\pi(a|s)\Big(r(s,a)+\gamma\sum_{s'}P_{ass'}V(s')\Big),\qquad (TV)(s) = \max_a\Big(r(s,a)+\gamma\sum_{s'}P_{ass'}V(s')\Big). \]

    Then \(V_{\pi,\gamma} = T_\pi V_{\pi,\gamma}\), \(V_{*,\gamma} = TV_{*,\gamma}\), and for total value \(V_{*,\tau} = TV_{*,\tau-1}\) with \(\gamma = 1\). Finite-horizon value iteration is just backward induction: start at \(\tilde V_0 = 0\) and apply \(T\) exactly \(T\) times.

    Shortest path. With reward \(-d(s,a)\) on edges and a bonus of \(|\mathcal V|d_{\max} = 70\) for arriving at the destination, total value iteration is Bellman–Ford run backward from the destination. The lecture’s graph gives value 60 from node 1: \(70 - (3 + 2 + 5)\) along 1→3→4→7, reached once the horizon is at least 3.
    5.2

    Why it converges: contraction

    For any \(V, V'\) and state \(s\), let \(a\) be the action that maximizes the first bracket. Then

    \[ (TV)(s) - (TV')(s) \le \gamma\sum_{s'}P_{ass'}\big(V(s')-V'(s')\big) \le \gamma\max_{s'}|V(s')-V'(s')| = \gamma\|V-V'\|_\infty. \]

    The first step uses \(\max_af_a - \max_ag_a\le\max_a(f_a-g_a)\); the second uses that each row of \(P_a\) is a probability distribution. Swapping \(V\) and \(V'\) gives the other side, so \(\|TV-TV'\|_\infty\le\gamma\|V-V'\|_\infty\). With \(V_* = TV_*\):

    \[ \|V_*-\tilde V_{k+1}\|_\infty = \|TV_*-T\tilde V_k\|_\infty\le\gamma\|V_*-\tilde V_k\|_\infty\le\cdots\le\gamma^{k+1}\|V_*-\tilde V_0\|_\infty. \]

    For a practical stopping rule, \(\|\tilde V_k - V_*\|_\infty\le\frac{\gamma}{1-\gamma}\|\tilde V_k - \tilde V_{k-1}\|_\infty\).

    5.3

    Asynchronous updates and Gauss–Seidel

    The contraction argument works one state at a time: updating \(V(s)\leftarrow(TV)(s)\) brings that entry within \(\gamma\|V_*-V\|_\infty\) of the truth. So any schedule that updates every state infinitely often converges, even with stale values passed between processors.

    Gauss–Jacobi updates every state from the same old vector. Gauss–Seidel sweeps states one by one and uses new values as soon as they exist. When information flows in one direction, the sweep order matters a lot. In river swim, reward sits at the right end; a right-to-left Gauss–Seidel sweep carries it across the whole river in one pass, while Jacobi moves it one state per iteration.

    Order matters both ways. HW5’s mopbot found Gauss–Jacobi needing fewer iterations than a fixed-order Gauss–Seidel sweep. In-place updates help only when the sweep follows the direction in which value propagates.

    5.4

    Structure: linear-quadratic control

    Value iteration can work on infinite state spaces when the iterates keep a simple form. With \(x' = ax+bu+w\), \(w\sim\mathcal N(0,\sigma^2)\), and \(r = -x^2-cu^2\), every iterate is a constant plus \(\eta_kx^2\). Substituting into \(T\) and completing the square in \(u\):

    \[ V_{k+1}(x) = \sigma^2\sum_{k'\le k}\eta_{k'} - x^2 + \eta_ka^2x^2 + \max_u\big((\eta_kb^2-c)u^2 + 2\eta_kabxu\big),\quad u^* = -\frac{\eta_kab}{\eta_kb^2-c}x, \]
    \[ \eta_{k+1} = -1 + a^2\Big(\eta_k - \frac{\eta_k^2b^2}{\eta_kb^2-c}\Big). \]

    One scalar recursion replaces an infinite table. With discounting, \(a^2\to\gamma a^2\) and \(c\to c/\gamma\). The fixed-point equation is quadratic with two roots; the negative one gives \(V_{*,\gamma}(x) = \frac{\gamma\sigma^2\eta_*}{1-\gamma} + \eta_*x^2\).

    5.5

    Gain and bias by value iteration

    Without discounting, \(J_k = T^kJ_0\) grows linearly: \(J_k\approx k\lambda_* + V_*\). So the increments estimate the gain and the remainder estimates the bias:

    \[ \tilde\lambda_{k+1} = J_{k+1}-J_k\to\lambda_*,\qquad \tilde V_k = J_k - k\tilde\lambda_k. \]

    This works when every gain-optimal policy is aperiodic; with periodicity the increments oscillate. The notes conjecture a damped fix, \(J_{k+1} = \gamma_kJ_k + (1-\gamma_k)TJ_k\) with \(\sum\gamma_k = \infty\), \(\sum\gamma_k^2\lt\infty\).

    6.1

    Policy evaluation is a linear solve

    For a fixed policy the max disappears from the Bellman equation, leaving \(|\mathcal S|\) linear equations.

    \[ V = r_\pi + \gamma P_\pi V \quad\Longrightarrow\quad V_{\pi,\gamma} = (I-\gamma P_\pi)^{-1}r_\pi. \]

    The inverse exists because \(\gamma P_\pi\) has spectral radius at most \(\gamma\lt1\), so \(I - \gamma P_\pi\) has the convergent Neumann series \(\sum_t\gamma^tP_\pi^t\). In code, solve the system rather than forming the inverse. The lecture plots evaluate fast-only and slow-only service for the capped queue: slow-only is better when the queue is short and much worse when it is long, which is exactly the shape that suggests a threshold.

    6.2

    The algorithm and why it works

    Start with any policy \(\pi_0\). Repeat: evaluate \(V_{\pi_k,\gamma}\), then let \(\pi_{k+1}\) be greedy with respect to it. Two properties of the operators do all the work.

    • Monotonicity: \(V\le V'\Rightarrow TV\le TV'\) and \(T_\pi V\le T_\pi V'\), because discounting and probabilities are nonnegative.
    • Max beats average: \(T_\pi V\le TV\) for every \(\pi\), with equality when \(\pi\) is greedy for \(V\).
    \[ V_\pi = T_\pi V_\pi\le TV_\pi = T_{\pi'}V_\pi \;\Rightarrow\; V_\pi\le T_{\pi'}V_\pi\le T_{\pi'}^2V_\pi\le\cdots\to V_{\pi'}. \]

    Each inequality after the first applies the monotone operator \(T_{\pi'}\) to the previous one, and the limit is \(V_{\pi'}\) by contraction. If nothing improves, \(V_\pi = TV_\pi\), which is the optimal Bellman equation, so \(\pi\) is optimal. With finitely many deterministic policies and strict improvement otherwise, the algorithm stops in finitely many steps.

    HW5 adds two views. Modified policy iteration applies \(T_{\pi_k}\) only \(m\) times instead of solving: \(m = 1\) is value iteration and \(m = \infty\) is policy iteration, and it converges for every \(m\) when \(TV_0\ge V_0\). Newton’s method on \(F(V) = TV - V\) has Jacobian \(\gamma P_\pi - I\), and one Newton step is exactly \(V_{k+1} = (I-\gamma P_{\pi_k})^{-1}r_{\pi_k}\), which explains the fast convergence.

    Approximate policy iteration

    When the state space is too big to store \(V\) (Tetris), replace exact evaluation with a fit \(\tilde V_\theta\approx V_{\pi_k,\gamma}\) and act greedily on the fit.     7.1

    The value LP

    Requiring \(V(s)\) to exceed every action’s backup is the same as requiring it to exceed the max, so one nonlinear constraint per state becomes \(|\mathcal A|\) linear ones.

    \[ \min_V\sum_sw(s)V(s)\quad\text{s.t.}\quad V(s)\ge r(s,a) + \gamma\sum_{s'}P_{ass'}V(s')\ \ \forall s,a \qquad\Longleftrightarrow\qquad \min\ w^\top V\ \text{s.t.}\ V\ge TV. \]

    Why the answer is \(V_*\). Any feasible \(V\) satisfies \(V\ge TV\). Apply monotonicity repeatedly: \(V\ge TV\ge T^2V\ge\cdots\to V_*\). So every feasible point dominates \(V_*\) componentwise, and \(V_*\) itself is feasible because \(V_* = TV_*\). With positive weights the objective is minimized only at \(V_*\), whatever the weights are.

    At the optimum, the binding constraint at each state is the one for an action that attains the max, so the binding constraints read off an optimal policy.

    8.1

    Real-time value iteration

    Asynchronous value iteration lets you pick which states to update. RTVI picks them by acting: at each step, take the greedy action, update the visited pair, and move on.

    \[ (FQ)(s,a) = r(s,a) + \gamma\sum_{s'}P_{ass'}\max_{a'}Q(s',a'),\qquad A_t\in\arg\max_aQ_t(S_t,a),\qquad Q_{t+1}(S_t,A_t) = (FQ_t)(S_t,A_t). \]

    \(F\) is monotone and a \(\gamma\)-contraction like \(T\), with fixed point \(Q_*\). If every pair were updated infinitely often, RTVI would converge to \(Q_*\). But a greedy trajectory may never try some actions, and a pessimistic start can lock out the best one: with one state, actions worth 1 and 0 per step, and \(Q_0 = (-1, 0)\), RTVI picks the second action forever and nothing changes.

    8.2

    Optimism

    The fix is to start optimistic, \(Q_0\ge Q_*\). Monotonicity keeps it that way: if \(Q_t\ge Q_*\), then \(FQ_t\ge FQ_* = Q_*\), so the update can’t push the visited entry below the truth.

    Under the stronger condition \(Q_0\ge FQ_0\), the iterates decrease monotonically, so they converge. Along the pairs visited infinitely often, the limit satisfies the Bellman equation of the greedy policy, which can’t exceed \(Q_*\), while optimism says it is at least \(Q_*\). So eventually only optimal actions are taken. An overestimated action gets tried, its estimate drops, and it is abandoned only once it is no longer better.

    HW7 queue. Rewards are negative, so \(Q_0 = 0\) is optimistic. RTVI reached \(\|V_t - V_*\|_\infty\le0.1\) after 75,672 steps, but \(\|Q_t - Q_*\|_\infty\) froze near 26.6: suboptimal entries stop being updated once they fall below the optimal ones.
    8.3

    Q-learning

    RTVI still needs \(\sum_{s'}P_{ass'}\), a sum over next states. Q-learning uses the one next state that happened, and smooths with a step size because a single sample is noisy:

    \[ Q_{t+1}(S_t,A_t) = Q_t(S_t,A_t) + \alpha_t\Big(\underbrace{r(S_t,A_t) + \gamma\max_aQ_t(S_{t+1},a) - Q_t(S_t,A_t)}_{\text{temporal difference}}\Big). \]

    The temporal difference compares two predictions of the same return: one made before the transition and one made after seeing \(S_{t+1}\). The theory comes from stochastic approximation. The sample mean is \(\bar X_{t+1} = \bar X_t + \frac{1}{t+1}(X_{t+1} - \bar X_t)\); replace the fixed target by a contraction \(f\) and the iteration \(\bar X_{t+1} = \bar X_t + \alpha_t(f(\bar X_t) + W_{t+1} - \bar X_t)\) still converges to the fixed point when \(\sum\alpha_t = \infty\) and \(\sum\alpha_t^2\lt\infty\). Q-learning is this with \(f = F\), so it converges if every pair is updated infinitely often.

    • Fixed step size: no convergence, but performance often improves and then chatters near optimal; smaller \(\alpha\) learns slower and settles closer.
    • Exploration: noise can push Q-learning below \(Q_*\) by chance, so either add an optimistic boost \(\Delta_t\) to each target, or dither with ε-greedy: random action with probability ε.
    • Function approximation: \(\theta\leftarrow\theta + \alpha\nabla_\theta Q_\theta(S_t,A_t)\cdot\text{TD}\). For a table, \(\nabla_\theta Q_\theta(s,a)\) is a one-hot vector and this is ordinary Q-learning.

    Check yourself

    Does optimistic RTVI make \(Q_t\to Q_*\)?

    Not necessarily. It guarantees eventually optimal actions and correct values along the optimal behavior, but suboptimal entries can freeze above \(Q_*\) once they stop being visited (HW7).

    Why does HW7’s Tetris RTVI need a step size?

    Many boards share one \(\theta_{h,o}\) but produce different targets. With \(\alpha = 1\) the parameter jumps to the latest board’s target; a small \(\alpha\) averages over the boards that share it.

    9.1

    Reinforce on a bandit

    A bandit is an MDP with one state: pull an arm, see a random reward from that arm’s fixed distribution, repeat.

    \[ A_t\sim\pi_{\theta_t},\qquad \theta_{t+1} = \theta_t + \alpha_tR_{t+1}\nabla_\theta\ln\pi_{\theta_t}(A_t). \]

    For the Gibbs (softmax) policy \(\pi_\theta(a) = e^{\theta_a}/\sum_{a'}e^{\theta_{a'}}\), think of \(\theta_a\) as a score. Its score function is

    \[ \nabla_\theta\ln\pi_\theta(a) = \nabla_\theta\Big(\theta_a - \ln\sum_{a'}e^{\theta_{a'}}\Big) = \mathbf 1_a - \sum_{a'}\pi_\theta(a')\mathbf 1_{a'}, \]

    a one-hot vector minus its mean. So the chosen arm’s score rises by \(\alpha(1-\pi_\theta(A_t))R\) and every other arm’s falls by \(\alpha\pi_\theta(a)R\).

    9.2

    Why it follows the gradient

    The average reward is \(\lambda_\theta = \sum_a\pi_\theta(a)r(a)\). Multiply and divide by \(\pi_\theta(a)\):

    \[ \nabla_\theta\lambda_\theta = \sum_ar(a)\nabla_\theta\pi_\theta(a) = \sum_a\pi_\theta(a)r(a)\frac{\nabla_\theta\pi_\theta(a)}{\pi_\theta(a)} = \sum_a\pi_\theta(a)r(a)\nabla_\theta\ln\pi_\theta(a) = \E\big[R_{t+1}\nabla_\theta\ln\pi_{\theta_t}(A_t)\,\big|\,\theta_t\big]. \]

    Each update is a noisy, unbiased gradient sample; small steps average the noise and the parameters follow a flow up the gradient. The trick requires \(\pi_\theta(a)\gt0\), which the softmax guarantees.

    9.3

    Baselines

    When both arms pay 1 most of the time (0.96 vs 0.94), every pull pushes the chosen arm up, so the policy chases whichever arm it happened to pull. Subtract a baseline \(B_t\), such as the running mean of rewards, and only better-than-usual outcomes reinforce:

    \[ \theta_{t+1} = \theta_t + \alpha_t(R_{t+1}-B_t)\nabla_\theta\ln\pi_{\theta_t}(A_t),\qquad \E[B_t\nabla_\theta\ln\pi_\theta(A_t)] = B_t\sum_a\nabla_\theta\pi_\theta(a) = B_t\nabla_\theta 1 = 0. \]

    The baseline may depend on \(\theta_t\) and the history but not on \(A_t\). It changes the variance, not the expected direction.

    9.4

    The policy gradient theorem and actor-critic

    With states, the immediate reward is replaced by the relative action value, weighted by how often each pair is visited (Sutton et al.; Konda and Tsitsiklis):

    \[ \nabla_\theta\lambda_\theta = \sum_{s,a}\mu_\theta(s,a)Q_{\pi_\theta}(s,a)\nabla_\theta\ln\pi_\theta(a|s),\qquad \theta_{t+1} = \theta_t + \alpha_t\big(Q_{\pi_\theta}(S_t,A_t) - V_{\pi_\theta}(S_t)\big)\nabla\ln\pi_\theta(A_t|S_t). \]

    Baselining with \(V_{\pi_\theta}\) gives the advantage \(Q - V\), which averages to zero under \(\pi\) (HW7). Like policy iteration, this raises the probability of actions with above-average value, but gradually. \(Q\) must be estimated: by a rollout from \((S_t, A_t)\), or by a critic \(\tilde Q_\psi\) trained with temporal differences:

    \[ d_{t+1} = R_{t+1} - \lambda_t + \tilde Q_\psi(S_{t+1},A_{t+1}) - \tilde Q_\psi(S_t,A_t),\quad \psi\mathrel{+}=\beta_td_{t+1}\nabla_\psi\tilde Q_\psi(S_t,A_t),\quad \lambda\mathrel{+}=\beta_td_{t+1}. \]

    For a horizon \(T\), update once per episode with reward-to-go from the same episode: \(\theta_{\ell+1} = \theta_\ell + \alpha_\ell\sum_{t\lt T}\hat Q_t\nabla\ln\pi_{\theta_\ell}(A_t|S_t)\), \(\hat Q_t = \sum_{k\ge t}R_{k+1}\).

    Language models. State = context window, action = next token, \(\theta\) = network weights. For math problems whose answers are hard to produce but easy to verify, sample \(T\) tokens, reward the episode by whether the answer checks out, and apply reinforce.

    Why can’t the baseline depend on \(A_t\)?

    The zero-mean argument pulls \(B_t\) outside the sum over actions. If \(B_t\) varied with \(A_t\) it couldn’t be pulled out, and the update would be biased.

    With rewards always positive and no baseline, what happens to an arm that’s pulled?

    Its score always rises, however bad it is relative to the other arm. Progress comes only from the better arm rising slightly faster on average, which is why learning is slow and erratic.
